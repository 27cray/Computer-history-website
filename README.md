# Computer-history-website


Codespace Setup:
- Install Live Server from the Extensions Marketplace (Tile on left hand side, looks like 4 blocks)
    To use tool click on button in bottom right hand side of screen to "Go Live"
        Opens Preview
- To commit to tree(update)
    Click commit and push or it won't fully commit to the page, with a small message so you can look back on previous actions.
        Also when dealing with multipule pages of code you also need to use the pull feature so all codes are synced up.
